# Knife Fights

A local multiplayer sword-fighting game

Made in C++ using raylib.

## Features

- Local 2-player sword combat
- Three sword levels
- Thrust attacks
- Sword parrying
- Perfect parries
- Charged overhead attacks
- Overhead leap attacks
- Hit-stop
- Screen shake
- Impact zoom
- Sudden death
- Score and time limits
- Player colour selection
- Sound effects
- Procedural placeholder music

## Controls

### Player 1

| Key | Action |
|---|---|
| A / D | Move |
| W / S | Sword level |
| Space | Thrust |
| Left Shift | Charge overhead |

### Player 2

| Key | Action |
|---|---|
| Left / Right | Move |
| Up / Down | Sword level |
| Right Shift | Thrust |
| Enter | Charge overhead |

## How to Play

Match your sword level against an incoming thrust to parry it.

Changing sword level at exactly the right moment allows a perfect parry, stunning your opponent for longer.

The overhead attack cannot be parried, but requires a full charge and commits the player to a dangerous forward leap.

First player to reach the score limit wins.

If a timed match ends in a draw, the game enters sudden death and the first player to score wins.
